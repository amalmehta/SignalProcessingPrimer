# File Structure

```
signal_processing_primer/
├── README.md                         Overview: screenshots, course map, links
├── signal_processing_primer.md       The original brief (with assumptions and changelog)
├── project.yml                       XcodeGen spec — the source of truth for the Xcode project
├── Signal Processing Primer.xcodeproj  Generated from project.yml (committed so it opens without XcodeGen)
│
├── Signal Processing Primer/         The app
│   ├── App/
│   │   ├── SignalProcessingPrimerApp.swift  App entry: main window, Settings scene (⌘,), Help ▸ Send Feedback…
│   │   └── AppState.swift                   Preferences keys, ProgressStore (quiz/progress), FeedbackStore (local file)
│   ├── Course/
│   │   ├── Course.swift                     Data model: Module → Lesson → Block, QuizQuestion, DemoKind
│   │   └── CourseContent.swift              All lesson text, formulas, real-world boxes and quizzes
│   ├── DSP/
│   │   ├── DSP.swift                        1-D signal processing: tones, aliasing, quantization, FFT, windows,
│   │   │                                    STFT, convolution, biquad filters, compressor
│   │   └── ImageDSP.swift                   2-D: test card, image kernels, 8×8 DCT, JPEG quantization, PSNR
│   ├── Audio/
│   │   └── TonePlayer.swift                 Plays generated buffers through AVAudioEngine
│   ├── Views/
│   │   ├── ContentView.swift                Sidebar + lesson detail, welcome page, progress bar, feedback button
│   │   ├── LessonView.swift                 Renders a lesson's blocks, the demo card and the quiz
│   │   ├── Components.swift                 Palette, sliders, play buttons, LinePlot (Swift Charts + hover), image view
│   │   ├── FeedbackView.swift               Feedback sheet
│   │   ├── SettingsView.swift               Settings window: Reading, Sound, Images, Progress tabs
│   │   └── Demos/
│   │       ├── DemoView.swift               DemoKind → view router, shared audio helpers
│   │       ├── FoundationsDemos.swift       Lessons 1–3: sine mixer, aliasing, quantization
│   │       ├── FrequencyDemos.swift         Lessons 4–6: spectrum, windowing, spectrogram (+ renderer)
│   │       ├── FilteringDemos.swift         Lessons 7–9: convolution/echo, biquad designer, compressor
│   │       └── PictureDemos.swift           Lessons 10–12: image kernels, JPEG, frame rate & shutter wheel
│   └── Resources/Assets.xcassets            App icon (generated by scripts/make_icon.swift)
│
├── Tests/
│   ├── DSPTests.swift                       Numerical checks of every DSP routine
│   └── CourseTests.swift                    Content integrity, progress persistence, feedback file
│
├── scripts/
│   ├── make_icon.swift                      Draws the app icon at every macOS size
│   ├── screenshots.sh                       Captures each lesson's demo into docs/images/
│   └── window_id.swift                      Helper for screenshots.sh (finds the app's window)
│
└── docs/
    ├── INSTRUCTIONS.md                      Setup, run, test, use
    ├── SYSTEM-DESIGN.md                     Architecture, flows, decisions, limits
    ├── FILE-STRUCTURE.md                    This file
    └── images/                              Screenshots used by the README
```

The `build/` folder holds build output and is git-ignored.
